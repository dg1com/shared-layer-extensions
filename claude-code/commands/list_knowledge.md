---
description: List what the shared knowledge base contains, optionally under a path
argument-hint: [path]
---

Use the `shared-layer` MCP server's `list` tool to show what the knowledge base contains. Start at `$ARGUMENTS`, or at `/` if that is empty.

Call the `begin` tool first if you have not this session. Then show the folders and files at that path as a short list with each one's title and description. Do not open files or descend into folders unless asked; end by saying which folder to pass to list deeper.
